# 📱 Инструкция: установка семейного чата на телефон

## Что ты получишь
Настоящее приложение на каждом телефоне с иконкой на экране.
Все сообщения хранятся в облаке (Firebase) — бесплатно.

---

## Шаг 1: Создай базу данных Firebase (5 минут, бесплатно)

1. Открой **https://console.firebase.google.com**
2. Войди через Google аккаунт
3. Нажми **"Создать проект"** → введи название (например: `family-chat`) → Далее → Создать
4. В левом меню выбери **Realtime Database**
5. Нажми **"Создать базу данных"**
6. Выбери регион: **europe-west1** → Далее
7. Режим безопасности: выбери **"Начать в тестовом режиме"** → Создать

### Получи настройки подключения:
1. Нажми шестерёнку ⚙️ рядом с "Обзор проекта" → **Настройки проекта**
2. Прокрути вниз до раздела **"Ваши приложения"**
3. Нажми иконку **</>** (Веб-приложение)
4. Введи имя: `family-chat` → **Зарегистрировать**
5. Скопируй блок `firebaseConfig` — он выглядит так:
```js
const firebaseConfig = {
  apiKey: "AIza...",
  authDomain: "family-chat-xxx.firebaseapp.com",
  databaseURL: "https://family-chat-xxx-default-rtdb.firebaseio.com",
  ...
};
```

---

## Шаг 2: Вставь настройки в код

1. Открой файл **`index.html`** любым текстовым редактором
   (на Windows — Блокнот, на Mac — TextEdit)
2. Найди строки в начале файла:
```
apiKey: "ВСТАВЬ_СЮДА",
authDomain: "ВСТАВЬ_СЮДА.firebaseapp.com",
...
```
3. Замени все `"ВСТАВЬ_СЮДА"` на твои реальные данные из Firebase

---

## Шаг 3: Загрузи на Vercel (бесплатный хостинг)

1. Открой **https://vercel.com** → Sign Up → войди через GitHub
   (Если нет GitHub — зарегистрируйся бесплатно на https://github.com)
2. На главной Vercel нажми **"Add New Project"**
3. Выбери **"Upload"** (или перетащи папку `family-chat`)
4. Загрузи все файлы из папки:
   - index.html
   - manifest.json
   - sw.js
   - icon-192.png
   - icon-512.png
5. Нажми **"Deploy"**
6. Через 30 секунд получишь ссылку вида: `https://family-chat-xxx.vercel.app`

---

## Шаг 4: Установи на каждый телефон

### 📱 iPhone / iPad:
1. Открой Safari (только Safari, не Chrome!)
2. Перейди по ссылке `https://family-chat-xxx.vercel.app`
3. Нажми кнопку **Поделиться** (квадрат со стрелкой вверх) внизу экрана
4. Прокрути и нажми **"На экран «Домой»"**
5. Нажми **"Добавить"**
6. Готово! Иконка появится на экране

### 🤖 Android:
1. Открой Chrome
2. Перейди по ссылке
3. Нажми **три точки** (меню) в правом верхнем углу
4. Нажми **"Добавить на главный экран"** или **"Установить приложение"**
5. Нажми **"Добавить"**
6. Готово!

---

## Шаг 5: Поделись ссылкой

Просто отправь всем членам семьи ссылку в WhatsApp/Telegram:
> "Привет! Установи наш семейный чат: https://family-chat-xxx.vercel.app
> Открой в Safari (iPhone) или Chrome (Android), затем добавь на экран домой!"

## ❓ Частые вопросы

**Платно ли это?**
Нет. Firebase даёт 1 ГБ базы данных бесплатно. Vercel бесплатен для личных проектов.

**Чужие люди увидят нашу переписку?**
Нет, если ты не дашь им ссылку. База данных Firebase в тестовом режиме открыта, но URL никто не знает. Для полной защиты можно настроить правила доступа в Firebase Console.

**Можно добавить/убрать членов семьи?**
Да — открой `index.html`, найди массив `MEMBERS` в начале скрипта и отредактируй имена и эмодзи.

**Уведомления не приходят?**
Это обычный чат без push-уведомлений. Чтобы добавить уведомления, нужна более сложная настройка Firebase Cloud Messaging.
